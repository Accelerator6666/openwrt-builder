# GeoWAN Console v0.4.0

Status: development preview; target-router acceptance is still required.

Base: `feature/geowan-console-v0.3.0`, which has been installed and accepted on the target OpenWrt router.

## Blacklist management UI

- Keep the existing read-only `list_bans` and `get_ban` RPC APIs; no new RPC method is introduced.
- Add selectable page sizes: 20, 50, and 100 records.
- Add first-page and last-page navigation alongside previous/next.
- Add first-seen time, latest sampled event time, and remaining ban duration to the blacklist table.
- Highlight records with one hour or less remaining.
- Show active/expired state in the IP detail panel and provide a close control.
- Ignore stale detail responses when the user selects another IP or closes the detail panel.
- Display sub-minute durations in seconds instead of rounding them down to zero minutes.

## Compatibility and safety

- No SQLite schema migration.
- No nftables rule, set, timeout, WAN policy, DNAT, PPPoE, daed, or proxy-routing change.
- No new listener or TCP/UDP port.
- No manual ban/unban operation; the UI remains read-only.
- The existing 5-second counter sampling, 15-second inventory/log scan, and 5-minute reconciliation remain unchanged.
- Port/protocol filters and event timestamps are based on retained, rate-limited kernel log samples, not a complete connection history.
- Remaining ban duration is calculated when the list is queried; re-run the query to refresh displayed durations.

## Validation

Run on the source checkout:

```sh
python3 -m unittest discover -s tests -v
python3 -m py_compile agent/geowan_agent.py agent/geowan_geoip.py agent/geowan_rpc.py rpcd/geowan
sh -n install.sh uninstall.sh scripts/*.sh preflight.sh
node --check luci/overview.js
```

Before target-router installation:

1. Confirm v0.3.0 is healthy and keep its backup.
2. Run `sh preflight.sh`; stop if any required nftables object or dependency fails.
3. Install from the `feature/geowan-console-v0.4.0` branch.
4. Verify status version `0.4.0`, monitor service, database integrity, read-only RPC calls, pagination, filters, and detail display.
5. Confirm nftables sets and existing WAN rules are unchanged.

Do not treat source-level tests as a substitute for target-router acceptance.
